# 💰 Cash Flow Management

**Cash Flow Management** — это веб-приложение на Django для управления денежными потоками. Оно позволяет пользователям создавать, редактировать, удалять и фильтровать финансовые записи, а также управлять справочниками (статусы, типы, категории) через удобный интерфейс с модальными окнами и AJAX.

---

## 🚀 Основные возможности

### Управление записями

- Создание, редактирование и удаление финансовых записей
- Фильтрация записей по дате, статусу, типу и категории

### Управление справочниками

- Добавление, редактирование и удаление статусов, типов и категорий через модальные окна
- Поддержка иерархии категорий (родительские и дочерние)
- Проверка зависимостей: нельзя удалить объекты, используемые в записях или подкатегориях

### Интерфейс

- Современный дизайн с использованием Bootstrap 5
- AJAX для операций со справочниками (без перезагрузки страницы)
- Динамическое обновление категорий в формах в зависимости от выбранного типа

### Архитектура

- Class-Based Views (CBVs)
- Сервисный слой (RecordService, ReferenceService) для бизнес-логики
- Модульная структура, легко расширяемая

---

## ⚙️ Технологии

- **Backend**: Django 4.2
- **Frontend**: Bootstrap 5, JavaScript (AJAX)
- **База данных**: SQLite (по умолчанию; можно заменить на PostgreSQL)
- **Управление зависимостями**: Poetry
- **Зависимости**: `django-bootstrap5==23.3`

---

## 📦 Установка

### Требования

- Python 3.8+
- Poetry
- Git (опционально)

### Установка шаг за шагом

```bash
# Клонируем репозиторий
git clone https://github.com/BahaGit2002/cashflow_project.git
cd cashflow_project

# Установка зависимостей через Poetry
poetry install

# Активация окружения
poetry shell

# Создайте файл .env
cp .env.example .env
# или создайте вручную:

# Применение миграций
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser

# Сбор статических файлов (опционально)
python manage.py collectstatic

# Запуск сервера разработки
python manage.py runserver
